John Dee MixColumns Mirror Maze — Team Area

A working tool, not a mock-up. Every value on this page is computed live: the GF(28) weave is the AES MixColumns transform braided into crypto/og_mixcolumns.c, and the Goldilocks panel runs the same matrix over Fp, p = 264 − 232 + 1, with exact arithmetic.

1 · GF(2^8) — the AES weave and its mirror

One state column. Enter four bytes (hex), then run the weave forward or traverse the mirror (inverse weave 0E 0B 0D 09) back.

Full 4×4 state (AES layout, column-major). The weave runs per column.

2 · Goldilocks Fp — the same matrix over a prime field

Four field elements (hex 0x… or decimal, each < p = 18446744069414584321). XOR tangles become additions mod p; the taps 01/02/03 become ×1/×2/×3. det M = −35 ≢ 0 (mod p), so M is invertible over Fp and the mirror traversal below is the true matrix inverse, not a display reflection.

Notes

GF(28) core verified against FIPS-197: column (DB 13 53 45) weaves to (8E 4D A1 BC) and mirrors back exactly; the C implementation additionally proves its multiplication tables against the field definition for all 6 × 256 entries and roundtrips 10,000 random columns. Goldilocks core cross-checked against exact integer arithmetic, including inverse roundtrips.
